- **[Active Directory Security Monitoring](https://github.com/mariust47/active-directory-labs/tree/main/ad-domain-security-monitoring)**: department GPOs and audit policies, Performance Monitor on the DC, and Event Viewer analysis of logons and account creation (4624, 4625, 4720).
